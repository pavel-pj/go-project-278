## Сокращатель ссылок (Go)

#### Запуск на localhost: 
```bash
docker compose build
docker compose up -d
make start
```
#### фронт будет доступен по указанному адресу ( к примеру localhost:5173)

#### Запуск только серверной части:
```bash
make main
```

#### Тесты:
```bash
make test
```

#### Линтер:
```bash
make lint
```
